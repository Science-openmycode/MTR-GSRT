# Oldenburg Dataset Assessment

Oldenburg uses local projected coordinates, not WGS84.  The main `oldenburg.dat` file is generated by an A* road-network generator, so it is useful for route-shape and road-constrained pattern tests, but it is not a real GPS human-mobility dataset.

## Verdict

- `oldenburg.dat` is usable as a second benchmark for road-constrained trajectory-pattern realism.
- It should be presented as a simulated road-network dataset, not as real GPS data.
- The `eps=1.0` LDPTrace pickle is coordinate-compatible with `oldenburg.dat`; several other pkl files appear to use a different coordinate system and should not be compared without conversion.
- Because Oldenburg is already generated by shortest-path style routing, it is especially useful for testing whether our methods can match route geometry, length, and OD patterns. It is weaker evidence for human behavioral realism.
